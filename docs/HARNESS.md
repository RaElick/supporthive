# Как настроен агентский харнес разработки

Проект пишется агентом (Claude Code); ручная работа — постановка задач, ревью и отладка.
Настройка, которая позволяет агенту выполнять длинные задачи без деградации:

| Механизм | Файл | Зачем |
|---|---|---|
| Инструкции проекта | `CLAUDE.md` (+ `AGENTS.md` для других харнесов) | Команды, жёсткие архитектурные правила, где что лежит. Короткий — читается в каждой сессии целиком |
| Документы-якоря | `docs/ARCHITECTURE.md`, `DECISIONS.md`, `PROGRESS.md` | Внешняя память между сессиями: агент не выводит заново уже принятые решения |
| Хук автопроверки | `.claude/settings.json` + `.claude/hooks/check.mjs` | После каждой правки `.py` — pytest, после `.ts/.tsx` — `tsc`. Ошибка сразу возвращается агенту (exit 2), он чинит её в том же шаге, а не через 20 правок |
| Сабагент `reviewer` | `.claude/agents/reviewer.md` | Независимое ревью только на чтение со свежим контекстом, по чек-листу правил проекта |
| Сабагент `ux-tester` | `.claude/agents/ux-tester.md` | Прогон пользовательских сценариев через API работающего сервера |
| Skill `add-agent` | `.claude/skills/add-agent/SKILL.md` | Пошаговый рецепт нового агента: подгружается только когда нужен, не раздувает базовый контекст |
| Skill `add-routing-strategy` | `.claude/skills/add-routing-strategy/SKILL.md` | Рецепт стратегии + как честно её оценить на симуляторе |
| Разрешения | `.claude/settings.json` | Тесты/сборка/симулятор без подтверждений — меньше прерываний на длинных задачах |
| Запуск для проверки в браузере | `.claude/launch.json` | Агент сам поднимает сервер и проверяет UI |

## Уроки, попавшие в правила

Ошибки, которые агент допустил при первой реализации и которые теперь закреплены в `CLAUDE.md`:

- `useEffect(() => ref.current?.scrollIntoView())` — эффект вернул значение, React упал при очистке.
  Найдено проверкой в браузере → правило «эффекты возвращают только функцию очистки или ничего».
- Относительные `NavLink` во вложенных `<Routes>` дали бесконечный редирект `/dashboard/dashboard/…` →
  правило «ссылки во вложенных роутах абсолютные».
- Ключевые слова классификатора `оплат` и `плат` считались дважды → тест-кейс на неоднозначную фразу.
