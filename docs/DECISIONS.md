# Решения

Формат: дата — решение — почему.

- **2026-11-17 — Python/FastAPI + React/TS, SQLite в разработке.** Docker на машине нет; SQLAlchemy
  позволяет перейти на PostgreSQL сменой `DATABASE_URL`. Flutter не используется: веб-виджет и
  панель оператора проще и быстрее для демонстрации; Dart остаётся для лаб курса.
- **2026-11-17 — Собственный агентский харнес вместо LangChain/LangGraph.** Требование курса и
  предмет исследования: нужен полный контроль над сборкой контекста (`ContextBuilder`).
- **2026-11-17 — Любой OpenAI-совместимый API, без SDK.** Позволяет подключить YandexGPT/GigaChat
  через совместимый прокси, OpenRouter или локальную модель (Ollama/LM Studio/vLLM) без изменений кода.
- **2026-11-17 — У каждого агента обязательная эвристика.** Система работает без ключей (демо, тесты,
  CI), а эвристики дают базовую линию для сравнения с LLM в исследовании.
- **2026-11-17 — Агенты чистые, побочные эффекты только в `pipeline.py`.** Агенты тестируются без БД
  и переиспользуются симулятором.
- **2026-11-17 — Каждый вызов агента пишется в `AgentRun`** (вход, выход, отчёт о контексте, режим,
  длительность, ошибка). Сырьё для исследовательской части и отладки.
- **2026-11-17 — События клиенту по каналу `customer:<id>`, а не `ticket:<id>`.** Виджет подписан до
  того, как создаётся новое обращение; канал клиента переживает смену обращений.
- **2026-11-17 — Telegram через «голый» Bot API (long polling на httpx).** Без фреймворка: один файл,
  не нужен публичный URL для вебхука.
