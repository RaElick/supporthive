# SupportHive — мультиагентная CRM клиентской поддержки

## Для таблицы тем

**Название:** Мультиагентная CRM-система клиентской поддержки с интеллектуальной маршрутизацией обращений и аналитикой качества обслуживания

**Описание:** Веб-система для службы поддержки. Клиенты пишут в Telegram-бот или в виджет чата на сайте,
все обращения попадают в единую очередь. Агент-классификатор определяет тему, приоритет и кратко
формулирует суть обращения. Агент-маршрутизатор назначает обращение оператору с учётом его
компетенций, текущей загрузки и истории успешно закрытых заявок по этой теме (сравниваются
стратегии: общая очередь, сопоставление навыков, LLM-маршрутизация). Агент-подсказчик предлагает
оператору черновик ответа на основе базы знаний и истории диалога. После закрытия обращения
клиент ставит оценку, а агент-аналитик проверяет диалог (вежливость, решена ли проблема, нарушения
регламента). Администратор видит дашборды: среднее время первого ответа и решения, оценки по
операторам, распределение тем, аномалии («простые» заявки, которые обрабатываются слишком долго).

**Исследовательская часть:** сравнение стратегий маршрутизации на симуляторе нагрузки и влияние
стратегий контекстной инженерии (порядок и приоритет фрагментов контекста, бюджет токенов,
вытеснение старых сообщений) на качество ответов агентов. Агентский контур написан без
LangChain/LangGraph — собственный минимальный харнес.

**Стек:** Python (FastAPI, SQLAlchemy), React + TypeScript, Telegram Bot API, любой OpenAI-совместимый LLM API.
