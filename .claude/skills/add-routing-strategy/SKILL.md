# Новая стратегия маршрутизации

1. В `backend/app/agents/router.py`:
   - функция `route_<name>(ticket: TicketInfo, cands: list[Candidate]) -> Decision` (или async, если LLM);
   - работать только с `available(cands)`; при пустом пуле — `Decision(None, "нет свободных операторов", ...)`;
   - `reason` — человекочитаемое обоснование на русском (его видят оператор и админ);
   - добавить имя в `STRATEGIES` и ветку в `route(...)`. LLM-ветки — под `try/except` с откатом на `skills`.
2. Стратегия видит только то, что есть в продакшене (`Candidate`): навыки, загрузку, историю оценок.
   Скрытую «компетентность» из симулятора использовать нельзя — иначе сравнение нечестное.
3. Тесты в `backend/tests/test_agents.py`: выбор на типовых кандидатах, пустой пул, тай-брейки.
4. Оценка: `python -m app.simulate --tickets 600 --seed 1` и `--rate 2.0` (перегрузка), несколько seed.
   Новая стратегия попадёт в таблицу, если добавить её в список `strategies` в `simulate.main`.
   Результаты (таблица + выводы) — в `docs/RESEARCH.md`.
5. В UI стратегия появится автоматически (`/api/admin/settings` отдаёт `STRATEGIES`); описание добавить
   в словарь `desc` в `frontend/src/pages/Admin.tsx`.
